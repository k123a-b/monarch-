# Card Monarchs

A multiplayer browser card game where Italian brainrot meets a satirical royal court. Every price, wager, balance, and payout is fictional virtual GBP, represented by integer pence. There are no payment, deposit, withdrawal, or redemption features.

The vanilla JavaScript SPA includes eight pack collections (including the UK Collection of 40 celebrities and 30 locations), an animated card reveal with optional synthesized audio, up to three packs opened side by side, an inventory with vault and bulk sales, weighted ten-minute global pots, five-minute matched-stake friend tables, reserved two-party trades, active-play rewards, daily quests, five leaderboards, and an accounting ledger.

## Technology

Vite bundles the HTML, CSS, and framework-free JavaScript frontend. A Vercel Function (`api/index.ts`) provides the JSON API and Google sign-in. Supabase provides managed PostgreSQL, accessed with Drizzle and the `pg` driver; transactional game operations use explicit transactions, per-account and per-round locking on pooled connections, and recent pulls use Drizzle ORM. Independent players can mutate their accounts concurrently while shared pot rounds remain serialized. Auth.js (`@auth/core`) handles Google OAuth and issues a signed, HTTP-only session cookie. Vercel Image Optimization serves generated pack/meme artwork and externally sourced leader portraits.

## Local development

Use Node.js 22 or later. Install dependencies with `npm install`, copy `.env.example` to `.env.local` and fill it in, apply the schema with `npm run migrate`, then run `npx vercel dev` (it runs Vite and the API together). See "Deploying to Vercel" below for the hosted setup.

`npm test` runs deterministic pack and game-rule checks. Optional deployment API checks run when `CARD_MONARCHS_TEST_URL` names a running deployment. Database integration checks require `CARD_MONARCHS_DATABASE_TESTS=1` and a `DATABASE_URL`. These create temporary test accounts, exercise the actual API handler and database transactions, and clean up afterward. Do not use production for database tests.

The Vercel and Supabase migration has not been deployed or run against a live database from the environment it was written in; verify sign-in, a pack purchase and image loading on a preview deployment first.

## Accounts and Google login

Sign-in is Google only; email/password accounts were removed with Netlify Identity. Each Google login must have a verified email. The Google subject remains the primary account key, and a unique verified-email link lets the same Google account recover its existing game account if its Auth.js subject changes. A new account is suggested a unique username based on the Google profile name, then must save a public username in the first-sign-in prompt. Open **Settings** to change the name, switch Google accounts, or log out. A new account receives a single £5.00 welcome credit when its game account is first provisioned. No age field is collected. Accounts created under Netlify Identity are not carried over: ids differ, so players start fresh.

Create a Google OAuth client (Google Cloud Console, APIs & Services, Credentials, OAuth client ID, Web application). The sign-in button is disabled until all three are set. Sessions last 30 days and are verified server-side on every request; the browser never supplies identity. New accounts must save a unique public username in a first-sign-in prompt before using the app; existing accounts retain their current usernames.

## Economy and fairness

Each of the eight packs has its own per-card odds, expressed as integers out of 100,000,000, plus separate per-pack chase, Mythic jackpot, Payday, Windfall, and Secret rolls. Alpha/Mystery Gold is isolated from regular pools and numbered using a database sequence. Apex guarantees at least a Crown by replacing its lowest card if necessary. Chase, Mythic and Secret rolls are per pack; each replaces only one eligible lower-value, non-special card. Normal template duplicates are avoided until a rarity pool is exhausted. Every set's value ladder is built around one carrier tier per pack: the cheaper tiers are pocket change and the carrier sits at roughly twice that pack's price, with the tiers above it stepping upward from there. A pack therefore either holds a card worth more than it cost or it plainly does not, instead of paying back its stake one boring card at a time. The largest payouts still come from Crown, chase and Mythic pulls, so thousands remain rare and card-gated. Pack value may be above or below the purchase price; card values enter the balance only when cards are sold.

Mythic is an ultra-rare jackpot tier with one exclusive card in each pack, worth roughly 40×–500× the pack price and rolled separately at odds from 1 in 20,000 to 1 in 200,000. A Mythic replaces the pack's lowest ordinary card and has its own odds row, reveal animation, and JACKPOT announcement. Mythic cards are excluded from set-completion requirements and normal rarity pools. The current jackpots are The Final Algorithm (£90 at 1 in 20,000), The Empty Throne (£1,000 at 1 in 60,000), Vault Zero (£10,000 at 1 in 60,000), Solar Sovereign (£24,000 at 1 in 100,000), Zero Point Monarch (£16,000 at 1 in 80,000), The Last Superpower (£5,000 at 1 in 200,000), The First Franchise (£90,000 at 1 in 150,000), and The National Treasure (£25,000 at 1 in 100,000).

Secret cards are a hidden trophy tier: one classified card per pack, worth £24 to £8,000, with a dedicated dossier animation and its own glitch effect. They never appear in normal rarity pools, Alpha/Mystery Gold, chase rolls, Mythic rolls, the free starter pack, or the Card Index. Every player starts with a 0.05% base Secret chance, and each equipped Crown card adds 0.08 percentage points, capped at +0.40%; Secret card powers can add a little more. The roll is independent of the rarity bands and runs only during a player's first successful pack purchase of each UTC day — every pack in that purchase gets the roll, and the window closes whether or not a Secret is found. The UK Pack's Secret is Free Palestine, worth £8,000, with artwork bundled at `public/img/free-palestine-secret.webp`. Every Secret card also grants a power: bonus Secret chance, a deterministic 20% (UK: 10%) discount on one randomly chosen pack type for the rest of the UTC day, Epic and Crown shifts, or 50p off every third pack. Secret discounts are shown before purchase, apply to the actual price paid, and never reduce a price below zero; they are separate from the normal loadout Crown/Epic shifts.

The win-boundry gates were scrapped, and the target was narrowed to the one question a player actually asks: does this pack hold a card worth more than I paid? A pack either does or it does not, and the boring in-between outcome — every card worth a little under its share of the price — was engineered out of the ladder. Across all eight packs the 100,000-pack audit now measures 37.6%–51.5% price-recovering openings and 48.5%–62.4% losses without loadout bonuses, including the every-tenth-pack Epic floor. Losses of 25% or more of the pack price occur in 35.0%–60.1% of openings depending on the pack, and 27.4%–48.9% of openings return twice the price or more. Brainrot has per-card 65.3% Common, 22.7% Uncommon, 11% Epic and 1% Crown odds, with Epics at £4.00–£4.80 against the £2 price. Royalty has 78.6% Common, 11% Uncommon, 10% Epic and 0.4% Crown, so its £10.73–£16.86 Epic tier carries the £6 pack. Vault has 82.4% Uncommon, 11% Epic, 6.5% Crown and 0.1% Alpha, and its £37.45–£74.90 Crown tier carries the £25 pack. Apex costs £150 for five cards with 69.5% Uncommon, 13% Epic, 10% Crown and 7.5% Alpha, and keeps its Crown guarantee even though a Crown now sells for well under half the pack price — the Alpha serial is that pack's carrier. Fortnite has 44.35% Common, 41.62% Uncommon, 7.13% Epic, 6.9% Crown and 0.00001% Alpha. World has 47% Common, 40.5% Uncommon, 11% Epic and 1.5% Crown. Fast Food has 52% Common, 29% Uncommon, 11% Epic and 8% Crown. The UK Pack costs £600 for five cards with 65.5% Common, 22% Uncommon, 11% Epic and 1.5% Crown odds; its Epic tier is valued at about £1,000-£1,200 so Epics now carry the pack. Within every pack the rarity odds now descend from the cheapest tier to the rarest, so no rarer tier is likelier than a cheaper one. Existing inventory rows are re-valued onto the new ladder by `db/migrations/20261029090000_revalue_felt_win_ladder.sql`, which writes the current catalogue value for every rollable template; account balances are untouched, retired templates keep their stored value, and the Keir Starmer penalty card still mints at exactly −£2.50, matching the live database check constraint.

Each pack also has a separate 3% Windfall roll. Its Chase-rarity trophy card is worth 5.5× the pack's listed price: £11 Brainrot, £33 Royalty, £137.50 Vault, £825 Apex, £687.50 Fortnite, £55 World, £1,650 Fast Food and £3,300 UK. A hit replaces the cheapest eligible ordinary card only if it is cheaper than the Windfall; Alpha, Chase, Mythic and Secret cards are protected. Actual 5×–10× outcomes are approximately 3.5%–7.2%, not a guaranteed payout range on each hit. Windfall cards are excluded from normal/starter pools and Card Index objectives, preserving existing set IDs and reward claims. The published 3% is per pack, not per card or an every-33rd-pack promise.

This higher-payout virtual economy deliberately permits positive expected returns: the site is not meant to keep the majority of the money. The 100,000-pack audit measures about 134.1%–179.8% average card sell value per listed price, with comeback bonuses reported separately; it enforces no below-100% ceiling and no fixed loss-rate or RTP boundary. The gates require every pack to genuinely win (price-recovering openings), genuinely lose (including openings that return less than 75% of the price), pay at least twice the price on a fifth or more of its openings, keep the 2×–5× and 5×–10× bands alive, and produce more clear wins than 1×–2× price recoveries, with zero failed milestone guarantees and valid Payday/Windfall/Mythic templates. Losses remain possible, and inventory value is not credited until sold.

Every tenth successful purchase per account, across all pack types, now guarantees an Epic or better. The server reads the existing persisted `accounts.packs` counter under the purchase transaction lock; failed purchases do not advance it, and natural rare pulls do not reset it. If the milestone pack has no Epic or better, its lowest card is replaced by an independently selected Epic from that pack’s collection before the unchanged chase roll. Apex keeps its stronger Crown guarantee. Existing players keep progress from their lifetime pack count. Card sell values remain varied, fixed in integer pence and visible before selling; rarity guarantees do not promise profit.

The comeback promise tracks consecutive money-losing packs on `accounts.loss_streak`, counted per pack rather than per purchase: a pack is a loss when its cards sell for less than that pack's share of the price paid. After three losses in a row, the next pack is opened with no Common cards — every Common result is upgraded to Uncommon, so Epic, Crown, Alpha, chase, Mythic and Secret odds are untouched. The server spends the promise when it applies it, and a comeback pack that also loses counts as the first loss of the next streak instead of a fourth straight loss. A package of several packs can therefore contain the comeback pack at its exact position while later packs return to normal. The counter resets on any win, is persisted outside the milestone counter, and is shown in the shop and the purchase dialog. Comeback packs are a bonus above the published base odds; their additional returns are measured separately.

Payday is a moderate-win tier on top of the comeback promise. The Monarch Vault, Apex Alpha, Fortnite Drop, Fast Food Legends and UK packs each carry one Payday card at a separate 1-in-25 per-pack roll, independent of the rarity bands, chase and Mythic jackpot. A Payday hit swaps the pack's lowest ordinary card for a Chase-rarity card worth about 2.1× that pack's price — £52 The Vault Key, £310 Apex Sigil, £260 Golden Llama, £620 Golden Receipt or £1,260 The Golden Ticket (UK) — which normally lands the pack in the 2×–5× band on its own; simultaneous specials can return more. Every pack keeps a 22.8%–43.7% chance of a 2×–5× return in the audit once natural Crown, chase and Mythic combinations are counted. The roll only replaces an ordinary card, so Alpha, Chase, Mythic and Secret pulls are never downgraded. The Vault and Apex rarity bands, the Fortnite/Fast Food bulk tiers and every set's per-rarity value ladder were retuned to fund the tier, and both the odds screen and the per-pack chase line list the Payday odds. Payday cards are trophy pulls: they are excluded from the Card Index so existing set requirements and claimed rewards do not shift.

The £10 World Leaders Pack has four cards. Its per-card odds are 47% Common, 40.5% Uncommon, 11% Epic, and 1.5% Crown, with no Alpha. Ordinary World Epics sit in a £21.00–£24.00 band, about twice the pack price, so a single Epic is a win on its own rather than value smeared thinly across four cards. Some Common flags are worth 9p, 13p, or 18p, and national-flag cards keep those authored penny values rather than the set's value ladder. Kim Jong Un is exclusive to the separate 1-in-45,000 pack chase roll, worth £15,000 virtual GBP, and applies a +2% Epic bonus outside the loadout cap. His reveal triggers a screen shake; reduced-motion preferences suppress the shake. Andy Burnham is a £77.87 Epic with a five-second center-screen portrait flight captioned “Just a normal bloke”; Benjamin Netanyahu (£973.33) and Donald Trump (£500) are Crown cards with dedicated reveal animations. The pack's Mythic jackpot is The Last Superpower, £5,000 at 1 in 200,000.

Global pot winner probability is proportional to stake with no house rake. As soon as exactly one human enters a round, the system Pot Bot matches that player's total contribution from its unlimited virtual balance: the total prize pool is twice the human stake, and the human receives 2× their stake if they win. The bot automatically sits out and its matching stake is removed as soon as another human enters. The bot participates in the same weighted draw and may win, so the human is not guaranteed a payout. Friend tables escrow equal stakes and pay exactly twice the stake to the winner after five minutes. Unjoined tables refund their host. Requests settle overdue games before relevant game actions; a scheduled function also settles and creates rounds every minute. Settlement is idempotent, transaction-locked, and reflected in each player's ledger. Anonymous pot views show live server data; bot entries are created only for the matching condition above.

Friends can also send each other virtual cash from the Friends tab. A gift moves 1p–£100 in whole pence between two accounts that are friends; self-gifts and bots are rejected, and each account can send at most 10 gifts per UTC day. Both ledger entries are written in the same transaction as the balance updates, so a gift either moves the exact amount or changes nothing. The sender's account row is locked for the transfer, the daily count comes from the sender's own ledger, and the recipient's balance updates through the same ledger helper as every other credit. Gifts are fictional and never convert to real money.

Active play sends visible-tab heartbeats every 30 seconds, only treating a tab with recent interaction as active. The server credits at most 45 seconds per heartbeat. Every 10 active minutes pays a reward starting at £1.00 and growing by £1.00 per step, capped at £15.00 per UTC day; payouts are recorded in the ledger. Every account, including accounts created before the feature, can open one free starter pack in Rewards for one card from the Brainrot, Royalty, or World Leaders collection. Its rarity odds are 55% Common, 35% Uncommon, 9% Epic, and 1% Crown; it cannot award Alpha or chase cards and does not count as a paid pack milestone. The server allows one claim per account and records it when the card is granted. Browser visibility is an anti-idle signal, not a tamper-proof bot-detection system.

Rewards also includes one server-recorded daily spin per account and UTC day: 40% no prize across three slices, 25% for £1, 20% for £2, 10% for £5, 4.9% for £10, and 0.1% for the £50 jackpot. Positive prizes are credited to the virtual balance and ledger in the same transaction that marks the spin complete.

Four daily quests reset at 00:00 UTC: open one pack (£2.00), open three packs (£3.00), pull an Epic or better card (£3.00), and sell three cards (£2.00) — £10.00 in total. The server records progress from actual pack, sell, and pull operations; each quest pays once per UTC day through the ledger helper, and a stale state from a previous day is reset before it is read. The Rewards marker on the navigation only appears when the free starter pack, the day's spin, or a completed quest is actually available; completed Card Index sets mark the Index tab instead.

Every completed Card Index set offers one permanent reward claim: either +0.50 percentage points of Epic chance or +0.10 percentage points of Crown chance, at most four of each per account (+2.00% Epic and +0.40% Crown). Once both account-wide caps are full, a completed set instead offers a choice between virtual cash — £50 for a set containing a Crown card, £25 for a set containing an Epic card, and £10 otherwise — or the set badge. Claiming either marks the set rewarded. The browser hides claims that are not complete, not signed in, or already rewarded; the server re-checks completion, ownership history, the caps, and that the set is still unclaimed before crediting anything.

Every card has a fixed whole-pence sell value; loadout powers depend on rarity. Most Common cards have no power-up, while a few give a 0.02 percentage point Epic nudge, a 0.35 point Uncommon nudge or a 10p recurring discount. Uncommon cards move Uncommon odds by up to 0.80 percentage points, with a 0.03 point Epic lift on one profile and a small stumble on another. Epic cards are now the tier where a loadout starts to pay for itself: 0.40 and 0.32 percentage point Epic boosts, one 0.20 point Uncommon boost, one card with no power-up and one small setback, so five Epic cards reach +2.00 of the +2.50 point Epic cap instead of barely denting it. Crown cards remain the strongest regular tier, and their four profiles vary: Epic boosts run from 0.25 to 0.60 percentage point and Crown boosts from 0.03 to 0.20 percentage point, so some Crown cards trade Crown odds for Epic or Uncommon instead of all maxing the same stat; powers do not guarantee a pull. Alpha is a separate rarity and card type represented by the one-off Mystery Gold card (+1.50 Epic, +0.10 Uncommon, +0.50 Crown). Mythic cards carry the single strongest power at +2.00 Epic and +1.00 Crown. Renegade Raider increases Crown odds by 0.50 percentage point. Chase cards are always an upgrade: each named chase has its own positive Epic, Uncommon or Crown boost, and no Chase profile rolls a downgrade. The UK Secret, Free Palestine, now sits on the same Vault-tier power profile as the other premium Secrets — +1.50 Epic, +0.30 Crown, a 20% random-pack discount and bonus Secret chance — because it guards the most expensive pack. Pack reveals show the total card sell value against the actual pack price, so a pull can be worth less or more than the pack; card values enter the balance only when cards are sold. Players start with three available cards in **Loadout**, then unlock slot four for £80 and slot five for £160, in order; multi-pack openings upgrade to two packs for £120 and three for £240. Combined loadout adjustments are capped at +0.40 percentage points for Uncommon odds, +2.50 percentage points for Epic odds, and +1.00 percentage point for Crown odds; positive Epic shifts come from Common, then Uncommon. Equipping Kim Jong Un guarantees every second card in a pack is Uncommon or better, and his +2.00% Epic bonus sits outside the loadout cap. Equipped cards cannot be sold, vaulted, or offered in trades until unequipped.

Run `node scripts/balance-audit.mjs` for a reproducible 100,000-pack simulation including tenth-pack guarantees, median sell values, average returns, price-recovering and losing rates, openings that lose at least 25% of the pack price, separate 2×–5× and 5×–10× outcome bands, observed extremes and Mythic jackpots. The win-boundry percentages are gone: gates now require every pack to show winning and losing openings, at least some ≥25% losses, at least a fifth of openings returning twice the price or more, the 2×–5× and 5×–10× bands present, at least as many clear wins as 1×–2× price recoveries, finite returns, zero failed milestone guarantees, and valid Payday/Windfall/Mythic templates. The report prints `winsAtLeast2x` beside `smallWinsUnder2x`, so a ladder that drifts back toward boring refunds is visible in the table rather than only in the gate. A second 100,000-pack pass per pack follows every loss streak to three and then opens a comeback pack, reporting its win rate, average value and long-run return with comeback packs included. Those comeback figures are informational: a comeback pack is a bonus above the base odds. The audit also prints a 20,000-pack loadout sensitivity table comparing an end-game five-Crown loadout, the five strongest Epic cards and a five-Uncommon loadout, so the strength of the Epic and Crown caps and the shape of the mid-game progression ladder are measured rather than assumed. Secret rolls are not part of the audit because they are limited to one UTC day per player and require equipped Crown cards. The audit does not connect to the database or change live randomness. Results describe virtual inventory values, not automatic cash credits or guaranteed returns.

All economy mutations serialize with a PostgreSQL advisory transaction lock. Pack cards are inserted in one statement to shorten the write lock. Leaderboard reads use a separate read-only snapshot without acquiring the game write lock. Transactions bound lock waits to five seconds and individual statements to fifteen seconds; busy requests roll back and return a retryable error without automatic replay of purchases. Browser refreshes do not overlap, stale view responses are ignored, and forms reject duplicate submissions while a request is pending. This locking policy prioritizes correctness for an initial game population. Higher traffic should replace it with carefully ordered account, trade, and round locks. Mutations check the request origin, verify the Identity session, validate inputs, and scope cards/trades to their owners. Database constraints provide additional protection against negative balances, duplicate friendships, and invalid reservations.

## Slot room

**Slots** is a separate game tab, not a pack. `POST /api/slots` takes one `bet` in whole pence between £5.00 and £12,000.00 (`slotLimits` in `shared/rules.mjs`), checked twice on the server — once by the request integer bounds and again by `validSlotBet` — and the account balance is read before the roll so an oversized stake is rejected rather than settled. The stake debit and the win credit both go through the ledger-writing `change` helper inside the same purchase transaction and the same advisory lock as every other money mutation, so a spin either moves the exact amount or changes nothing, and a balance can never go negative. There is no client-supplied multiplier, outcome or reel data: `slotSpin` and `slotReels` run server-side on cryptographic `randomInt`, and the response only echoes what happened.

One million weighted parts decide the outcome: 600,000 (60%) miss and lose the stake, 350,000 pay 2×, 35,000 pay 3×, 10,000 pay 5×, 4,000 pay 10×, 800 pay 25× and 200 (0.02%) pay the 100× Monarch jackpot. Payouts are always `stake × multiplier`, so the bandit returns 93.5% of everything wagered on average and the house keeps 6.5%. Because the win is proportional to the stake, a £5 spin tops out at £500 — small stakes cannot mint millions, and the largest legal stake is the only way to reach £1,200,000. The face symbol is the jackpot line: `slotReels` never lets it appear outside a 100× win, and a losing spin deliberately lands two-of-a-kind about four times in five for the classic near-miss feel but can never read as three of a kind.

The page shows a stake keypad with quick presets and a Max button, three reels that scroll on the CSS `slot-scroll` keyframe, staggered per-reel settle transforms, and cabinet glow states for big (10×+) and jackpot wins. Pulling the lever centres the cabinet in the viewport so the reels are on screen when they stop. As soon as they settle, `#slot-pop` — mounted in `index.html` outside `#app` so a re-render cannot wipe it — flashes a centre-screen receipt with the amount credited or the stake lost, then clears itself roughly a second later (0.8s a miss, 1.0s a win, 1.5s a 10×+, 2.0s the jackpot). It sits over a dimming scrim with `pointer-events: none`, so it never blocks the next pull, and a new spin or navigating away dismisses it early. Reveal, reel and glow animation is suppressed on `prefers-reduced-motion`, which settles the reels straight to their final symbols and shows the receipt with no transition for 0.9s. Spin statistics (spins, wagered, returned) accumulate in browser memory only and reset on reload; they are presentation, never a server-side claim. All values are virtual.

## Deploying to Vercel

1. **Supabase.** Create a project. Under Connect, copy the _Transaction pooler_ connection string (port 6543) and use it as `DATABASE_URL`. Do not append `?sslmode=`. Run `DATABASE_URL=... npm run migrate` once, and again after any new file appears in `db/migrations/`. The last migration turns on row level security so Supabase's public Data API cannot read or write game tables; the server connects as the database owner, which bypasses it.
2. **Google.** Create the OAuth client described above.
3. **Vercel.** Import the repository (root directory: the folder holding `package.json`; framework preset Vite). Add environment variables: `DATABASE_URL`, `AUTH_SECRET`, `AUTH_GOOGLE_ID`, `AUTH_GOOGLE_SECRET`. Redeploy after the first set, then add your final domain to the Google redirect URIs.
4. **Settlement.** Overdue pots and tables are also settled whenever someone loads the pot or acts, but a scheduled sweep keeps them settled when nobody is online. `GET /api/cron/settle` runs it and requires `Authorization: Bearer $CRON_SECRET`. Per-minute schedules need a Vercel Pro plan; to enable one, set `CRON_SECRET` and add `"crons": [{"path": "/api/cron/settle", "schedule": "* * * * *"}]` to `vercel.json`. On the Hobby plan crons may run at most daily, and a per-minute entry makes the deployment fail, so none is configured by default.

## Loadout bonuses: Kim and the Crown bonus

Kim Jong Un in a loadout adds a flat +2% Epic chance (2,000,000 of the 100,000,000 odds) on top of the normal loadout cap, alongside his guarantee that every second pack card is Uncommon or better. Extra copies of Kim do not stack. Any Crown bonus, whether from a loadout card or a permanent set reward, also raises each pack's chase-card chance: every 0.1% of Crown bonus makes the chase 10% more likely (`CHASE_BONUS_SCALE` in `shared/catalog.mjs`), so the +1.00% Crown loadout cap doubles the chase chance rather than multiplying it sixfold. With no Crown bonus the chase is the original 1-in-N roll. Every equipped Crown card also adds 0.08 percentage points to the daily Secret roll; the total Secret chance is capped at +0.40% and is only rolled on the first successful pack purchase of each UTC day. Secret cards are excluded from these Crown counts, so a Secret does not itself create more Secret chance.
